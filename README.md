# मनोकामना ट्रेडिंग कम्पनी | Manokamana Trading Company

> Panther E-Rickshaw & E-Scooter | The Battery Shop — Brijmanganj, Shahabad, UP

Professional business website for Manokamana Trading Company — an authorized Panther E-Rickshaw dealer offering sales, repair, assembly and warranty services in Brijmanganj, Shahabad, Uttar Pradesh.

## Features

- **Hindi-first** — Primary language is Hindi with English toggle
- **AI Chatbot** — Powered by Azure OpenAI (gpt-4.1-mini), answers in Hindi/English with voice input
- **Responsive** — Mobile-first design, works on all screen sizes
- **Dark Mode** — Toggle between light and dark themes
- **Photo Gallery** — Shop and inauguration photos with lightbox
- **Click-to-Call** — Prominent phone CTA for easy customer contact
- **WhatsApp Integration** — Quick message button

## Tech Stack

- [Next.js 16](https://nextjs.org/) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Azure OpenAI](https://azure.microsoft.com/en-us/products/ai-services/openai-service) for chatbot
- Web Speech API for voice input

## Getting Started

```bash
# Install dependencies
npm install

# Create .env.local from example
cp .env.example .env.local
# Edit .env.local with your Azure OpenAI credentials

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

```
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
AZURE_OPENAI_API_KEY=your-api-key
AZURE_OPENAI_FAST_DEPLOYMENT=gpt-4.1-mini
AZURE_OPENAI_API_VERSION=2025-01-01-preview
```
